# Python Module 01 — Code Cultivation

Object-oriented Python exercises that model a small garden-management system.

## Concepts

- Classes, instances, and constructors
- Instance, class, and static methods
- Encapsulation with properties and validation
- Inheritance and method overriding
- Polymorphism and class-level analytics
- Type annotations and executable scripts

## Exercises

| Directory | Exercise |
| --- | --- |
| `ex0` | Introduce structured plant data |
| `ex1` | Organize garden data with a `Plant` class |
| `ex2` | Simulate plant growth |
| `ex3` | Build plants through a factory pattern |
| `ex4` | Protect state with validation and accessors |
| `ex5` | Model flower, tree, and vegetable subtypes |
| `ex6` | Collect garden-operation statistics |

## Requirements

Written for Python 3.10+ using only the standard library. Run an exercise from its directory, for example: `python3 ex6/ft_garden_analytics.py`.

This is an educational project from the 42 curriculum.
