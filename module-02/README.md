# Python Module 02 — Garden Guardian

Python exception-handling exercises framed as resilient smart-garden data processing.

## Concepts

- `try`/`except` control flow
- Converting and validating user input
- Raising meaningful exceptions
- Handling built-in error types
- Designing custom exception hierarchies
- Guaranteed cleanup with `finally`

## Exercises

| Directory | Exercise |
| --- | --- |
| `ex0` | Catch a first conversion error |
| `ex1` | Validate and raise exceptions deliberately |
| `ex2` | Distinguish common built-in error types |
| `ex3` | Define garden-specific exceptions |
| `ex4` | Clean up watering operations with `finally` |

## Requirements

Written for Python 3.10+ with no third-party dependencies. Run an exercise directly, for example: `python3 ex4/ft_finally_block.py`.

This is an educational project from the 42 curriculum.
