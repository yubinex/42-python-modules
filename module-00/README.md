# Python Module 00 — Growing Code

Introductory Python exercises built around community-garden data.

## Concepts

- Console input and output
- Integer arithmetic and variables
- Conditional logic
- Iteration and recursion
- Function signatures and type annotations

## Exercises

| Directory | Exercise |
| --- | --- |
| `ex0` | Print a garden greeting |
| `ex1` | Read and display a garden name |
| `ex2` | Calculate a plot area |
| `ex3` | Total a three-day harvest |
| `ex4` | Check harvest readiness from plant age |
| `ex5` | Print a watering reminder |
| `ex6` | Count to harvest iteratively and recursively |
| `ex7` | Display typed seed-inventory information |

## Requirements

Written for Python 3.10+. Each exercise exposes the function requested by the subject; use the supplied course test helper or import a function from its exercise directory to run it.

This is an educational project from the 42 curriculum.
