# 42 Python Modules

A collection of Python learning modules from the 42 curriculum. Each module is kept in its own directory and retains its original Git history.

## Module 00 — Growing Code

Introductory garden-themed exercises covering console input and output, variables, arithmetic, conditional logic, loops, recursion, functions, and type annotations.

## Module 01 — Code Cultivation

Builds a small garden-management system while introducing object-oriented programming: classes, constructors, encapsulation, inheritance, polymorphism, and class/static methods.

## Module 02 — Garden Guardian

Focuses on robust error handling with `try`/`except`, explicit `raise`, built-in exception types, custom exception hierarchies, and `finally`-based cleanup.

## Module 03 — Data Quest

Uses game-data examples to practice Python collections: lists, tuples, sets, dictionaries, generators, and comprehensions, alongside command-line input and simple data analysis.

## Module 04 — Data Archivist

Explores file I/O and streams through archive-management exercises, including reading and writing files, standard input/output/error, context managers, and safe error recovery.

## Module 05 — Data Processing

Creates an extensible data-processing pipeline with abstract base classes, validated numeric/text/log processors, stream routing, and CSV/JSON export plugins.

## Module 06 — The Codex

Explores Python's import system: modules, packages, `__init__.py`, public exports, aliases, absolute and relative imports, and avoiding circular imports.

## Module 07 — Creature Systems

Implements a creature battle system to practice the Abstract Factory, composition, and Strategy design patterns, with validation for incompatible capabilities and battle strategies.

## Module 08 — Python Environments

Covers virtual environments, dependency management with pip and Poetry, NumPy/Pandas/Matplotlib workflows, and environment-based configuration and secret handling.

## Module 09 — Data Validation

Uses Pydantic to validate space-station, alien-contact, crew, and mission data with constrained fields, enums, nested models, and cross-field validation rules.
