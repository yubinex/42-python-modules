# Python Module 03 — Data Quest

Python collection exercises that build game-oriented data analysis tools.

## Concepts

- Command-line arguments and lists
- Numeric validation and score analytics
- Tuples and 3D geometry
- Set operations
- Dictionary-based inventory analysis
- Generators and comprehensions

## Exercises

| Directory | Exercise |
| --- | --- |
| `ex0` | Inspect command-line arguments |
| `ex1` | Analyze player scores |
| `ex2` | Track 3D coordinates |
| `ex3` | Compare achievement sets |
| `ex4` | Parse and analyze an inventory |
| `ex5` | Generate and consume game-event streams |
| `ex6` | Transform player data with comprehensions |

## Requirements

Written for Python 3.10+ using the standard library. Run an exercise directly, for example: `python3 ex1/ft_score_analytics.py 1500 2300`.

This is an educational project from the 42 curriculum.
