# Python Module 06 — The Codex

Python package exercises exploring module imports through an alchemical laboratory.

## Concepts

- Python modules and packages
- Package initialization with `__init__.py`
- `import` and `from ... import ...` styles
- Public package interfaces and aliases
- Absolute and relative imports
- Circular dependencies and deferred imports
- Type annotations, `flake8`, and `mypy`

## Parts

| Part | Focus | Demonstration scripts |
| --- | --- | --- |
| I — The Alembic | Local modules, packages, and package exports | `ft_alembic_0.py` – `ft_alembic_5.py` |
| II — Distillation | Nested imports and package aliases | `ft_distillation_0.py`, `ft_distillation_1.py` |
| III — The Great Transmutation | Absolute and relative imports | `ft_transmutation_0.py` – `ft_transmutation_2.py` |
| IV — Avoid the Explosion | Avoiding and demonstrating circular imports | `ft_kaboom_0.py`, `ft_kaboom_1.py` |

## Requirements

Written for Python 3.10+ using only modules created in this project. Run each demonstration from the repository root, for example: `python3 ft_transmutation_0.py`.

This is an educational project from the 42 curriculum.
