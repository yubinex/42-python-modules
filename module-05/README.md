# Python Module 05 — Code Nexus

An object-oriented data-processing pipeline demonstrating abstract classes and polymorphism.

## Concepts

- Abstract base classes and abstract methods
- Method overriding and subtype polymorphism
- Typed validation and ingestion interfaces
- Processor registration and data-stream routing
- Protocol-based plugin interfaces (duck typing)
- CSV and JSON output plugins

## Exercises

| Directory | Exercise |
| --- | --- |
| `ex0` | Implement numeric, text, and log processors |
| `ex1` | Route mixed input through a polymorphic data stream |
| `ex2` | Export processed output through CSV and JSON plugins |

## Requirements

Written for Python 3.10+ using only `abc` and `typing` imports. Run an exercise directly, for example: `python3 ex2/data_pipeline.py`.

This is an educational project from the 42 curriculum.
