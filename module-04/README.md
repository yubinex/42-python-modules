# Python Module 04 — Data Archivist

Python file and stream-management exercises for a fictional digital archive.

## Concepts

- Opening, reading, and closing files
- Transforming and writing file contents
- Command-line arguments and interactive streams
- Separating standard output from standard error
- Exception handling for file failures
- Context managers for safe resource handling

## Exercises

| Directory | Exercise |
| --- | --- |
| `ex0` | Recover and display an archived text file |
| `ex1` | Transform and save a new archive |
| `ex2` | Manage stdin, stdout, and stderr explicitly |
| `ex3` | Implement safe read/write archive access |

## Requirements

Written for Python 3.10+ with no third-party dependencies. Run an exercise directly, for example: `python3 ex0/ft_ancient_text.py <file>`.

This is an educational project from the 42 curriculum.
